# โฟลเดอร์ Fonts สำหรับระบบ Emergency Picking

## ไฟล์ที่ต้องอัปโหลดในโฟลเดอร์นี้:

1. **FREE3OF9.TTF** - Font หลักสำหรับบาร์โค้ด Free 3 of 9
2. **FREE3OF9X.TTF** - Font Extended (ถ้ามี)

## วิธีการได้มา:

1. ดาวน์โหลดจาก: https://www.dafont.com/free-3-of-9.font
2. แตกไฟล์ ZIP
3. อัปโหลดไฟล์ .TTF ทั้งหมดมาในโฟลเดอร์นี้

## การใช้งาน:

Font เหล่านี้จะถูกโหลดผ่าน @font-face ใน CSS ทำให้ทุกเครื่องที่เข้าถึงระบบสามารถแสดงบาร์โค้ดได้ถูกต้องโดยไม่ต้องติดตั้ง Font ในเครื่อง

## ความปลอดภัย:

- ไฟล์ Font ที่นี่เป็นแบบ Free License
- ไม่มีปัญหาลิขสิทธิ์ในการใช้งาน
